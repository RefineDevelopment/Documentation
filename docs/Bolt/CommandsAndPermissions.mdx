# Bolt Commands

This page lists the most important Bolt commands and the permissions checked by the current Bolt codebase. Some commands also have aliases; the main command name is shown first.

## Player Commands

| Command | Description | Permission |
| :--- | :--- | :--- |
| `/help` | View the practice help message. | None |
| `/profile` | Open your profile menu. | None |
| `/settings` | Open profile settings. | None |
| `/stats [player]` | View player statistics. | None |
| `/leaderboard` or `/lb` | Open leaderboards. | None |
| `/divisions` | Open the divisions menu. | None |
| `/cosmetics` | Open cosmetics. | None |
| `/shop` | Open the coin shop. | None |
| `/reward` | Claim the daily reward. | None |
| `/matchhistory` | View match history. | None |
| `/postmatch <player>` | View a post-match inventory. | None |
| `/duel <player>` | Send a duel request. | None |
| `/accept` | Accept a duel request. | None |
| `/queue select` | Open queue type selection. | None |
| `/queue join <queue>` | Join a specific queue. | None |
| `/queue leave` | Leave your current queue. | None |
| `/randomqueue` | Join a random unranked solo queue. | None |
| `/playagain` | Queue again or request a rematch after a match. | None |
| `/leave` | Leave your current match, queue, event, or activity. | None |
| `/map` | View the arena you are playing on. | None |
| `/spec <player>` or `/spectate <player>` | Spectate a player's match. | None |
| `/follow <player>` | Follow a player. | None |
| `/follow stop` | Stop following. | None |
| `/toggleduels` | Toggle duel requests. | None |
| `/togglev` or `/togglevisibility` | Toggle player visibility. | None |
| `/silent` | Toggle silent spectating mode. | `bolt.profile.silent` |
| `/edit` | Toggle edit/build mode. | `bolt.profile.edit` |
| `/spawn` | Teleport to the lobby spawn. | `bolt.profile.admin` |

| `/kit setEditInv <kit>` | Save kit editor inventory. |

| `/kit setQueueSlot <kit> <slot>` | Set queue slot. |

| `/kit viewArenas <kit>` | View arenas available for the kit. |
| `/kit wipeKits kit <kit>` | Wipe every player's custom layouts for a kit. |
