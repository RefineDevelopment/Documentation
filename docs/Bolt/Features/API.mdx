BoltAPI is the public integration layer for Bolt. It lets other plugins read player state, queue players, create duels, start matches, manage parties, inspect tournaments, work with kits, read stats, handle spectators, and listen to Bolt events.

## Installation

### Gradle

```kotlin
repositories {
    maven {
        name = "refine-public"
        url = uri("https://maven.refinedev.org/public-repo/")
    }
}

dependencies {
    compileOnly("xyz.refinedev.practice:BoltAPI:1.0.6")
}
```

### Maven

```xml
<repositories>
    <repository>
        <id>refine-public</id>
        <url>https://maven.refinedev.org/public-repo/</url>
    </repository>
</repositories>

<dependencies>
    <dependency>
        <groupId>xyz.refinedev.practice</groupId>
        <artifactId>BoltAPI</artifactId>
        <version>1.0.6</version>
        <scope>provided</scope>
    </dependency>
</dependencies>
```

## plugin.yml

Bolt is loaded through Retention, so add Retention as a soft dependency. This makes sure your plugin starts after the loader has initialized Bolt.

```yaml
name: MyPlugin
version: 1.0.0
main: com.example.MyPlugin
api-version: "1.13"
softdepend:
  - Retention
```

## Getting The API

```java
import xyz.refinedev.practice.api.BoltAPI;

BoltAPI api = BoltAPI.INSTANCE;
```

Access the sub-APIs from the singleton:

```java
ProfileAPI profileAPI = api.getProfileAPI();
ArenaAPI arenaAPI = api.getArenaAPI();
QueueAPI queueAPI = api.getQueueAPI();
DuelAPI duelAPI = api.getDuelAPI();
MatchAPI matchAPI = api.getMatchAPI();
PartyAPI partyAPI = api.getPartyAPI();
TournamentAPI tournamentAPI = api.getTournamentAPI();
KitAPI kitAPI = api.getKitAPI();
StatsAPI statsAPI = api.getStatsAPI();
LeaderboardAPI leaderboardAPI = api.getLeaderboardAPI();
IKnockbackHandler knockbackHandler = api.getKnockbackHandler();
```

## API Overview

| API | Use it for |
| :--- | :--- |
| `ProfileAPI` | Online/offline profiles, settings, match history, hotbar, visibility, and nametags. |
| `ArenaAPI` | Public arena lookup, available arenas for a kit, and selected arena flows. |
| `QueueAPI` | Solo/duo queues, queue counts, joining/leaving queues, and preferred arena queueing. |
| `DuelAPI` | Player duels, party duels, accepting/cancelling duel requests, and preferred arena duels. |
| `MatchAPI` | Current matches, match creation, ending, terminating, respawning, spectators, and post-match inventories. |
| `PartyAPI` | Party creation, invites, joins, kicks, promotions, settings, party matches, and spectating party matches. |
| `TournamentAPI` | Starting, joining, leaving, force-starting, cancelling, and ending tournaments. |
| `KitAPI` | Kit lookup, kit registration, selection items, and custom kit layout management. |
| `StatsAPI` | Player stat profiles and persistence. |
| `LeaderboardAPI` | Global and kit leaderboard reads/updates. |
| `KnockbackHandler` | Custom knockback hook integration for supported server forks. |

## Arena API

`ArenaAPI` was added in BoltAPI 1.0.5. Use it when your plugin needs to list arenas, validate maps, or let players select a preferred arena before queueing or dueling.

```java
ArenaAPI arenaAPI = api.getArenaAPI();

Collection<IArena> arenas = arenaAPI.getArenas();
Collection<IArena> nodebuffArenas = arenaAPI.getAvailableArenas(nodebuffKit);

IArena arena = arenaAPI.getArena("desert");
if (arena != null && arena.isPlayable() && arena.isWhitelisted(nodebuffKit)) {
    String displayName = arena.getDisplayName();
}
```

Useful `IArena` methods:

```java
String name = arena.getName();
String displayName = arena.getDisplayName();
ItemStack icon = arena.getDisplayIcon();
boolean enabled = arena.isEnabled();
boolean inUse = arena.isInUse();
boolean playable = arena.isPlayable();
boolean whitelisted = arena.isWhitelisted(kit);
String type = arena.getTypeName();
```

## Queue API

```java
QueueAPI queueAPI = api.getQueueAPI();

List<IQueue> soloQueues = queueAPI.getSoloQueues();
List<IQueue> duoQueues = queueAPI.getDuoQueues();

int totalQueued = queueAPI.getQueuedCount();
int rankedQueued = queueAPI.getQueuedCount(QueueType.RANKED);

boolean joined = queueAPI.joinQueue(player, kit, QueueType.UNRANKED);
boolean left = queueAPI.leaveQueue(player);
```

Preferred arena queueing:

```java
IArena preferredArena = api.getArenaAPI().getArena("desert");
boolean joined = queueAPI.joinQueue(player, kit, QueueType.UNRANKED, preferredArena);
```

Bolt will prefer the selected arena when the match is created and fall back to an available duplicate/arena if needed.

## Duel API

```java
DuelAPI duelAPI = api.getDuelAPI();

IProfileDuelRequest request = duelAPI.request(sender, target, kit);
IProfileDuelRequest sameRequest = duelAPI.getRequest(sender, target);

if (request != null && request.isActive()) {
    request.accept();
}
```

Selected arena duels:

```java
IArena arena = api.getArenaAPI().getArena("desert");
IProfileDuelRequest request = duelAPI.request(sender, target, kit, arena);
```

Party duel requests:

```java
IPartyDuelRequest partyRequest = duelAPI.request(partyA, partyB, kit);
IPartyDuelRequest arenaPartyRequest = duelAPI.request(partyA, partyB, kit, arena);

Collection<IDuelRequest> activeRequests = duelAPI.getActiveRequests();
duelAPI.cancel(partyRequest);
```

## Match API

```java
MatchAPI matchAPI = api.getMatchAPI();

IMatch match = matchAPI.getMatchByPlayer(player);
IMatch sameMatch = matchAPI.getMatch(player);
IMatch spectated = matchAPI.getMatchBySpectator(spectator);

Collection<IMatch> activeMatches = matchAPI.getMatches();
int fighting = matchAPI.getFightingCount();
int botMatches = matchAPI.getBotMatchesCount();
```

Creating matches:

```java
IMatch ranked = matchAPI.createSoloRankedMatch(playerA, playerB, kit);
IMatch unranked = matchAPI.createSoloUnrankedMatch(playerA, playerB, kit);
IMatch directSolo = matchAPI.createSoloMatch(playerA, playerB, kit, false);

IMatch team = matchAPI.createTeamMatch(teamAPlayers, teamBPlayers, kit, true);
IMatch partyFfa = matchAPI.createPartyFFAMatch(partyPlayers, kit);
IMatch partySplit = matchAPI.createPartySplitMatch(partyPlayers, kit);
IMatch partyVsParty = matchAPI.createPartyVsPartyMatch(partyAPlayers, partyBPlayers, kit, false);
```

Ending and cleanup:

```java
matchAPI.end(match, MatchEndReason.NORMAL);
matchAPI.terminateMatch(match);
matchAPI.fatalEnd(match, "Unexpected integration failure");

CompletableFuture<Boolean> blocksReset = matchAPI.resetBlocks(match);
CompletableFuture<Boolean> arenaReset = matchAPI.resetArena(match);
```

Spectator management:

```java
boolean added = matchAPI.addSpectator(match, spectator, playerA);
boolean removed = matchAPI.removeSpectator(match, spectator);
List<Player> spectators = match.getSpectatingPlayers();
```

Runtime match information:

```java
List<Player> alive = match.getAlivePlayers();
List<? extends IMatchPlayer> players = match.getMatchPlayers();
List<? extends IMatchTeam> teams = match.getMatchTeams();

IMatchPlayer winner = match.getWinningPlayer();
IMatchTeam winningTeam = match.getWinningTeam();

String duration = match.getDuration();
String lasted = match.getLasted();
boolean partyMode = match.isPartyMode();
```

## Party API

```java
PartyAPI partyAPI = api.getPartyAPI();

IParty party = partyAPI.createParty(leader);
partyAPI.invite(leader, invitedPlayer);
partyAPI.join(invitedPlayer, party);
partyAPI.promote(leader, newLeader);
partyAPI.kick(newLeader, kickedMember);
partyAPI.leave(member);
partyAPI.disband(newLeader);
```

Party match creation:

```java
boolean canQueueRanked = partyAPI.canQueue(party, true);

IMatch ffa = partyAPI.startFFA(party, kit);
IMatch split = partyAPI.startSplit(party, kit);
IMatch partyVsParty = partyAPI.startMatch(partyA, partyB, kit, false);

partyAPI.spectatePartyMatch(spectator, party);
```

Party settings:

```java
partyAPI.setOpen(party, true);
partyAPI.setAllInvite(party, true);
partyAPI.setMute(party, false);
partyAPI.setDuelRequests(party, true);
partyAPI.setLimit(party, 8);
```

Useful `IParty` methods:

```java
String name = party.getName();
PartyState state = party.getState();
boolean busy = party.isBusy();
boolean member = party.isMember(player.getUniqueId());
boolean leader = party.isLeader(player.getUniqueId());

IQueue queue = party.getQueue();
IMatch match = party.getMatch();
party.reloadHotbar();
party.reloadNameTag();
```

## Tournament API

```java
TournamentAPI tournamentAPI = api.getTournamentAPI();

ITournament tournament = tournamentAPI.getCurrentTournament();
ITournament byId = tournamentAPI.getTournament(tournamentId);

ITournament solo = tournamentAPI.startTournament(sender, kit, TournamentType.SOLO);
ITournament team = tournamentAPI.startTournament(sender, kit, TournamentType.TEAM, 2);

tournamentAPI.join(player);
tournamentAPI.leave(player);
tournamentAPI.forceStart();
tournamentAPI.cancelTournament();
tournamentAPI.end(TournamentEndReason.CANCELLED);
```

Useful `ITournament` methods:

```java
List<? extends IMatch> matches = tournament.getMatches();
List<Player> players = tournament.getPlayerParticipants();
List<IParty> parties = tournament.getPartyParticipants();

Player winningPlayer = tournament.getWinningPlayer();
IParty winningParty = tournament.getWinningParty();
Object winner = tournament.getWinningSubject();
boolean started = tournament.hasStarted();
```

In BoltAPI 1.0.6, `ITournament#hasStarted()` returns true only while the tournament state is `FIGHTING`. Waiting, starting, ended, and cleaned-up tournaments should be treated as not actively started.

## Kit API

```java
KitAPI kitAPI = api.getKitAPI();

IKit kit = kitAPI.getKit("nodebuff");
List<IKit> kits = kitAPI.getKits();
kitAPI.save();
```

Creating and registering a kit:

```java
IKit kit = kitAPI.builder()
    .name("customkit")
    .displayName("&6Custom Kit")
    .displayIcon(new ItemStack(Material.DIAMOND_SWORD))
    .build();

kitAPI.registerKit(kit, true);
```

Custom kit layouts:

```java
boolean hasLayouts = kitAPI.hasCustomInventories(player, kit);
IKitInventory[] layouts = kitAPI.getKitInventories(player, kit);

IKitInventory layout = kitAPI.getKitInventory(player, kit, 0);
boolean created = kitAPI.createKitInventory(player, kit, 0, "Main");
boolean saved = kitAPI.saveKitInventory(player, kit, 0, contents);
boolean renamed = kitAPI.renameKitInventory(player, kit, 0, "Potions");
boolean deleted = kitAPI.deleteKitInventory(player, kit, 0);

boolean openedManager = kitAPI.openKitEditManageMenu(player, kit);
boolean openedEditor = kitAPI.openKitEditor(player, kit, 0, true);
```

Layout wiping:

```java
kitAPI.wipeCustomInventories(player, kit);
kitAPI.wipeCustomInventories(player);

CompletableFuture<Long> wipedForKit = kitAPI.wipeKitsForKit(kit);
CompletableFuture<Long> wipedAll = kitAPI.wipeAllCustomInventories();
```

## Knockback Hook

```java
IKnockbackHandler knockbackHandler = api.getKnockbackHandler();

KnockbackHook hook = new KnockbackHook() {
    @Override
    public String getName() {
        return "MyKnockback";
    }

    @Override
    public boolean isApplicable() {
        return true;
    }

    @Override
    public void setKnockback(@NotNull Player player, @NotNull String profile) {
        // Apply your server fork's knockback profile.
    }
};

knockbackHandler.setHook(hook);
```

## Events

BoltAPI exposes match, spectator, profile, party, and tournament lifecycle events.

### Match Events

```java
@EventHandler
public void onMatchStart(MatchStartEvent event) {
    IMatch match = event.getMatch();
}

@EventHandler
public void onMatchEnd(MatchEndEvent event) {
    IMatch match = event.getMatch();
    MatchEndReason reason = event.getReason();
}

@EventHandler
public void onSoloWin(MatchWinEvent event) {
    IMatchPlayer winner = event.getWinner();
}

@EventHandler
public void onTeamWin(MatchTeamWinEvent event) {
    IMatchTeam winningTeam = event.getWinningTeam();
}
```

### Spectator Events

```java
@EventHandler
public void onSpectatorJoin(MatchSpectatorJoinEvent event) {
    Player spectator = event.getSpectator();
    IMatch match = event.getMatch();
}
```

### Party Events

```java
@EventHandler
public void onPartyCreate(PartyCreateEvent event) {
    IParty party = event.getParty();
}

@EventHandler
public void onPartyJoin(PartyJoinEvent event) {
    IParty party = event.getParty();
    Player player = event.getPlayer();
}
```

### Tournament Events

```java
@EventHandler
public void onTournamentStart(TournamentStartEvent event) {
    ITournament tournament = event.getTournament();
}

@EventHandler
public void onTournamentEnd(TournamentEndEvent event) {
    TournamentEndReason reason = event.getReason();
}
```
