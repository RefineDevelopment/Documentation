Admin commands are used for maintenance, setup, troubleshooting, data correction, arena repair, and staff-only match control.

## Core Admin Commands

| Command | Description | Permission |
| :--- | :--- | :--- |
| `/bolt info` | View Bolt information. | None |
| `/bolt reload` | Reload configuration files. | `bolt.admin.reload` |
| `/bolt theme <color>` | Set the global theme color. | `bolt.admin.theme` |
| `/bolt save` | Save configuration files. | `bolt.admin.save` |
| `/bolt update` | Force leaderboard/data update. | `bolt.admin.leaderboard` |
| `/bolt checkArenas` | Scan arenas for invalid/broken state. | `bolt.admin.arenas` |
| `/bolt reset` | Reset Bolt database collections. | `bolt.admin.reset` |

## Safety Notes

- Restart the server after adding or updating required plugins such as FastAsyncWorldEdit.
- Use `/bolt save` before large manual config changes.
- Use `/bolt reset` only when you intentionally want to clear Bolt data.
- Use `/bolt deleteEveryoneKitLayout` carefully; it removes player-created kit layouts for the selected kit.
- Use `/arena saveChanges` after editing standalone arenas so future resets use the newest schematic.
