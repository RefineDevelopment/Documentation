Arenas are the maps where Bolt creates matches. They can be simple no-build arenas, full build arenas, BedFight maps, Bridge-style maps, event arenas, or duplicated standalone maps for high player counts.

## Requirements

Bolt requires FastAsyncWorldEdit for schematic creation, saving, and paste resets. Use the Refine FAWE-Legacy fork for the best compatibility with Carbon and legacy practice setups:

[Download Refine FAWE-Legacy](http://github.com/refinedevelopment/fastAsyncWorldEdit-Legacy/releases/latest)

## Arena Types

| Type | Best for | Notes |
| :--- | :--- | :--- |
| Standard | No-build modes like NoDebuff, Boxing, Sumo, Combo | Shared arena style. Do not use it for modes that need heavy block changes. |
| Standalone | BuildUHC, BedFight, Bridge, Fireball Fight, BlockFight, WallRush, Spleef | One match per copy. Can be duplicated with `/arena scale`. |

Use standalone arenas for any mode that places, breaks, explodes, or resets blocks.

## Basic Setup

1. Install FastAsyncWorldEdit.
2. Paste or build the map in your arena world.
3. Use `/edit` to enter build mode.
4. Run `/arena create <name> <standard/standalone>`.
5. Place the required spawn markers or use the setup chat flow.
6. Select arena bounds with `/arena wand`.
7. Save spawn points and bounds with the setup prompts or update commands.
8. Finish with `/arena finish`.
9. Add supported kits with `/arena addKit <arena> <kit>`.
10. If the map is standalone, save the schematic with `/arena saveChanges <arena>`.

## Spawn And Special Locations

| Mode | Setup notes |
| :--- | :--- |
| Standard 1v1 | Set both player spawn points. |
| Team modes | Set both team spawn points and make sure the map has enough room for the configured team size. |
| Bridges / BattleRush | Configure portal/special cuboids and build height. |
| BedFight / WallRush | Place team-colored wool near beds and configure BedFight-style spawn/protection areas. |
| BlockFight | Use standalone arenas and configure kit BlockFight heart/void rules. |
| FFA / Party FFA | Set middle spawn and FFA radius when needed. |
| Events | Use `/event arena` commands for event-specific arenas. |

## Schematic Workflow

Standalone arenas use schematics for reset and duplicate management.

| Command | Use when |
| :--- | :--- |
| `/arena saveChanges <arena>` | You edited one arena and want to save the new schematic. |
| `/arena saveAllChanges` | You edited multiple arenas and want to save all schematic changes. |
| `/arena scale <arena> <amount>` | You need more or fewer duplicate copies for high traffic. |
| `/arena save` | You changed arena metadata and want to save arena config. |

Bolt also preserves skulls/heads placed above wool during paste resets, which is important for BedFight-style spawn markers and decorative map setups.

## Kit Whitelist

Arenas are linked to kits. A queue, duel, or selected arena flow can only use maps that are available for that kit.

| Command | Description |
| :--- | :--- |
| `/arena kits <arena>` | View kits linked to an arena. |
| `/arena addKit <arena> <kit>` | Allow a kit to use an arena. |
| `/arena removeKit <arena> <kit>` | Remove a kit from an arena. |
| `/arena copyKit <source> <target>` | Copy kit whitelist from one arena to another. |
| `/kit viewArenas <kit>` | View arenas available for a kit. |

## Troubleshooting

**Bolt says FastAsyncWorldEdit is missing**

- Install FAWE and restart the server.
- Use the Refine FAWE-Legacy release linked above for Carbon/legacy setups.

**A standalone arena does not reset**

- Make sure the arena has a saved schematic.
- Run `/arena saveChanges <arena>` after editing the map.
- Check console for FAWE/WorldEdit paste errors.

**Players spawn in the wrong place**

- Re-run `/arena updatePoints <arena>`.
- For BedFight-style maps, check wool/head markers and team colors.
- For Bridge-style maps, verify portal/special cuboids.

**Selected arena does not appear in duels or queues**

- Make sure the arena is enabled and playable.
- Make sure the kit is whitelisted on the arena.
- Make sure the player has `bolt.profile.arena` if arena selection is permission-gated in your setup.
