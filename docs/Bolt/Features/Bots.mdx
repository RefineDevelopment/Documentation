:::warning
Bots in Bolt are designed for 1.8 environments. They are not supported on 1.9+ combat servers.
:::

Bots provide AI opponents for practice. They can use predefined presets, custom presets, kit-specific behavior, custom knockback profiles, healing rules, and UHC-style item usage.

## What Bots Can Do

| Feature | Description |
| :--- | :--- |
| Presets | Configure different bot styles and difficulties. |
| CPS | Control click speed. |
| Ping | Simulate delayed reactions. |
| Range | Configure hit reach behavior. |
| Tryhard | Make the bot play more aggressively. |
| Strafe | Enable side movement. |
| W-tap | Enable W-tap movement. |
| Block hit | Allow block-hitting when the kit supports it. |
| Side pearl | Allow side pearl behavior in pearl kits. |
| UHC healing | Configure instant head, golden head, and golden apple thresholds. |
| Knockback profiles | Use separate player and bot knockback profiles. |

## Bot Permissions

| Permission | Allows |
| :--- | :--- |
| `bolt.bot` | Use bot duel, custom bot, and preset browsing commands. |
| `bolt.bot.custom` | Use custom bot presets from the menu. |
| `bolt.bot.admin` | Use bot admin/help/info commands. |
| `bolt.bot.knockback` | Manage bot knockback profiles with `/botkb`. |

## Commands

| Command | Description | Permission |
| :--- | :--- | :--- |
| `/bot duel <preset>` | Duel a bot preset. | `bolt.bot` |
| `/bot custom` | Duel a custom bot preset. | `bolt.bot` plus custom access where configured |
| `/bot presets` | View active bot presets. | `bolt.bot` |
| `/bot info <preset>` | View preset information. | `bolt.bot.admin` |
| `/bot addkit <preset> <kit>` | Add a kit to a bot preset. | Admin command |
| `/bot removekit <preset> <kit>` | Remove a kit from a bot preset. | Admin command |

## Bot Knockback Commands

All `/botkb` commands require `bolt.bot.knockback`.

| Command | Description |
| :--- | :--- |
| `/botkb save` | Save knockback profiles. |
| `/botkb reload` | Reload knockback profiles. |
| `/botkb list` | List profiles. |
| `/botkb view <profile>` | View profile values. |
| `/botkb set <profile>` | Set every bot to a profile. |
| `/botkb create <profile>` | Create a profile. |
| `/botkb edit <profile>` | Edit a value. |
| `/botkb delete <profile>` | Delete a profile. |
| `/botkb setdefault <profile>` | Set default profile. |
| `/botkb getdefault` | View default profile. |

## Kit Compatibility

Not every kit is a good bot kit. Avoid using bot presets for complex map-objective modes such as BedFight, Bridges, Fireball Fight, Pearl Fight, TNTSumo, and TopFight unless your setup has been specifically tested for it.

Good bot kit candidates:

- NoDebuff
- Soup
- Gapple
- BuildUHC-style combat without complex objective logic
- Boxing/Combo-style combat when configured carefully

## Tips

- Use `botBlockHit` on kits where bots should block-hit.
- Configure bot knockback separately from player knockback when needed.
- Test UHC healing thresholds before public release.
- Keep bot presets simple and predictable for players.
- Do not advertise bots as 1.9+ compatible.
