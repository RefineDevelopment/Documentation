Cosmetics let players customize their experience without changing gameplay balance. Bolt supports kill effects, kill messages, projectile trails, cloaks/trails, purchases, coins, and permission-based unlocks.

## Access

Players can open cosmetics with:

```bash
/cosmetics
```

Cosmetics can be unlocked through:

- Permissions.
- Coin shop purchases.
- Admin unlocks.
- VIP ranks or bundles.

## Permission Pattern

Cosmetic permissions are generated from the internal cosmetic name by removing underscores and lowercasing the result.

| Type | Wildcard | Example |
| :--- | :--- | :--- |
| Kill effects | `bolt.killeffect.*` | `bolt.killeffect.lightning` |
| Kill messages | `bolt.killmessages.*` | `bolt.killmessages.bbq` |
| Trails | `bolt.trails.*` | `bolt.trails.flame` |

Example VIP setup:

```bash
/lp group vip permission set bolt.killeffect.* true
/lp group vip permission set bolt.killmessages.* true
/lp group vip permission set bolt.trails.* true
```

## Admin Tools

| Command | Description | Permission |
| :--- | :--- | :--- |
| `/unlock <player> <permission>` | Unlock a cosmetic/product for a player. | `bolt.profile.unlock` |
| `/coins add/remove/set <player> <amount>` | Manage player coins. | `bolt.profile.coins` |

## Tips

- Cosmetics are visual only.
- Use wildcard permissions for rank bundles.
- Use individual permissions for store packages.
- Use coin prices for unlocks that should be earned by playing.
