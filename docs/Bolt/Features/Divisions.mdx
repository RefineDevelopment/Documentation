Divisions are a ranking system that separates players based on their ELO, wins, or other statistics.

## Customizing Divisions

Divisions are configured in the `divisions.yml` file in the Bolt plugin folder. You can:
- Add custom divisions
- Change ELO requirements
- Set division names and colors
- Configure rewards per division

## Using Divisions

Divisions can be used to:
- Give rewards based on division
- Assign ranks based on division
- Provide perks to higher divisions
- Display division in scoreboard/chat

## Tips

- Edit divisions.yml to customize the system
- Divisions are based on ELO by default
- Use divisions for progression systems
- Can integrate with permission plugins
