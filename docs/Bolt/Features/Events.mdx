Events are server-wide activities that players can join for community practice and competition. Bolt events use their own arenas, cooldowns, host flow, game rules, and admin tools.

## Common Event Types

Bolt event types are configurable, but typical practice setups use events such as:

- Sumo
- Spleef
- Parkour
- Other custom event modes configured by the server

## Event Flow

1. A staff member or configured host opens the event host menu.
2. Players join the active event.
3. The event starts automatically or staff force-start it.
4. Bolt handles event-specific rules and elimination.
5. Rewards, stats, tokens, or announcements can be handled by your configuration/integrations.

## Event Commands

| Command | Description | Permission |
| :--- | :--- | :--- |
| `/event` | View event help. | None |
| `/event host` | Open event host menu. | Host menu checks event/token rules |
| `/event chost <type>` | Console/staff host command. | `bolt.event.admin` |
| `/event info` | View current event information. | None |
| `/event join` | Join current event. | None |
| `/event leave` | Leave current event. | None |
| `/event clearCooldown <type>` | Reset event cooldown. | `bolt.event.cooldown` |
| `/event cancel` | Cancel current event. | `bolt.event.admin` |
| `/event forcestart` | Force-start current event. | `bolt.event.admin` |
| `/event setIcon <type>` | Set event icon. | `bolt.event.admin` |
| `/event setName <type> <name>` | Set event display name. | `bolt.event.admin` |

## Permissions

| Permission | Allows |
| :--- | :--- |
| `bolt.event.admin` | Manage events and event arenas. |
| `bolt.event.cooldown` | Reset event cooldowns. |
| `bolt.event.<event>` | Bypass event-token requirement for a specific event type when checked by the event host flow. |

## Game Rules

Events can use special game rules depending on the event type, including no-hunger and liquid-kill behavior. Configure these carefully per event so the arena and event rules match.

## Tips

- Use dedicated event arenas instead of normal duel arenas.
- Set build height and void/fall death height before public events.
- Use cooldowns to prevent event spam.
- Test event join/leave/cancel flow after changing event arenas.
- Give `bolt.event.cooldown` only to staff trusted to reset cooldowns.
