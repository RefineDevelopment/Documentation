Kits define how each match type behaves. A kit controls inventories, armor, potions, knockback, queue availability, duel availability, arena behavior, round behavior, block rules, explosion rules, bot support, and match commands.

## Supported Match Styles

Bolt's kit rules can be combined to create many practice modes:

- NoDebuff, Debuff, Soup, Combo, Boxing, Sumo, Stick Fight
- BuildUHC, Classic, Archer, Pearl Fight, Crystal PvP
- Bridges, BattleRush, MLGRush, BedFight, WallRush, BlockFight
- Fireball Fight, TNTSumo, Spleef, TopFight, OITQ, Wind Charge
- Party FFA, Party Split, Party vs Party, Best Of, respawn-based modes

## Important Kit Rules

### Queue And Duel Rules

| Rule | Description |
| :--- | :--- |
| `enabled` | Shows the kit to players and allows normal use. |
| `ranked` | Allows ranked queue support. |
| `unrankedQueueEnabled` | Allows unranked queue support. |
| `duelEnabled` | Allows direct duel support. |
| `editable` | Allows players to edit custom layouts for this kit. |

### Match Flow Rules

| Rule | Description |
| :--- | :--- |
| `bestOf` | Number of rounds needed to win. |
| `countdownTicks` | Fight countdown duration. |
| `newRoundCountdownTicks` | Countdown used between scored/Best Of rounds. |
| `respawnMode` | Enables respawn-based gameplay. |
| `respawnTicks` | Delay before a player respawns. |
| `resetArenaEachRound` | Resets the arena between scored rounds. |
| `noDrop` | Prevents item drops. |
| `noHunger` | Disables hunger loss. |
| `noRegen` | Disables natural regeneration. |
| `noFall` | Disables fall damage. |
| `allowCrafting` | Allows crafting/workbench interaction. |
| `actionBarHealth` | Sends opponent health in the actionbar. |
| `damageMultiplier` | Multiplies damage for the kit. |

### Build And Block Rules

| Rule | Description |
| :--- | :--- |
| `build` | Allows players to place blocks. |
| `blockRemoval` | Removes placed blocks after the match. |
| `breakMap` | Allows breaking map blocks. |
| `buildHeightDamage` | Punishes players above the configured build height. |
| `blockTimer` | Adds block placement cooldown. |
| `allowedBlocks` | Blocks players may place. |
| `disallowedBlocks` | Map blocks players may not break/place against. |
| `explosionBlacklist` | Blocks protected from Fireball/TNT explosions. |
| `dropWhitelist` | Blocks allowed to drop items when broken. |

| Rule | Description |
| :--- | :--- |

### Bot Rules

| Rule | Description |
| :--- | :--- |
| `botBlockHit` | Allows bot block-hitting for the kit. |
| `botKnockback` | Bot knockback profile for the kit. |
| `knockback` | Player knockback profile for the kit. |

## Inventories

Bolt stores multiple inventory concepts for each kit:

| Inventory | Used for |
| :--- | :--- |
| Main inventory | Items players receive in matches. |
| Armor | Armor players receive in matches. |
| Kit editor inventory | Base layout used by the kit editor. |
| Custom player layouts | Player-created layouts, up to the configured slot limit. |
| Selection items | Items shown when choosing custom layouts before a match. |

## Match Commands

Kits can run console commands when matches start or end.

Use `<player>` for player-based start/end command replacement. Older `{winner}` and `{loser}` examples may exist in old configs, but current Bolt command formatting supports player replacement through the match result flow.

Examples:

```bash
/kit addStartCMD nodebuff msg <player> Good luck!
/kit addEndCMD nodebuff eco give <player> 50
```

Common uses:

- Reward players.
- Broadcast match results.
- Trigger external plugins.
- Run rank, quest, or analytics commands.

## Kit Commands

All kit management commands require `bolt.kit.admin`.

| Command | Description |
| :--- | :--- |
| `/kit list [page]` | List kits. |
| `/kit manage` | Open kit management menu. |
| `/kit save` | Save all kits. |
| `/kit editor` | Open kit editor. |
| `/kit create <name>` | Create a kit. |
| `/kit delete <kit>` | Delete a kit. |
| `/kit toggle <kit>` | Enable or disable a kit. |
| `/kit info <kit>` | View kit information. |
| `/kit getInv <kit>` | Load kit inventory. |
| `/kit setInv <kit>` | Save held inventory as kit inventory. |
| `/kit getEditInv <kit>` | Load editor inventory. |
| `/kit setEditInv <kit>` | Save editor inventory. |
| `/kit setIcon <kit>` | Set icon from held item. |
| `/kit setName <kit> <name>` | Set display name. |
| `/kit setDescription <kit> <description>` | Set description. |
| `/kit setQueueSlot <kit> <slot>` | Set queue slot. |
| `/kit setKnockback <kit> <profile>` | Set player knockback. |
| `/kit setBotKnockback <kit> <profile>` | Set bot knockback. |
| `/kit setPriority <kit> <priority>` | Set menu sort priority. |
| `/kit viewArenas <kit>` | View arenas linked to the kit. |
| `/kit wipeKits kit <kit>` | Wipe all player layouts for a kit. |
| `/kit wipeKits player <player>` | Wipe a player's custom kit layouts. |
| `/kit deleteAll` | Delete all kits. |
| `/kit addAllowedBlock <kit> <block>` | Add allowed block. |
| `/kit removeAllowedBlock <kit> <block>` | Remove allowed block. |
| `/kit addDisallowedBlock <kit> <block>` | Add disallowed block. |
| `/kit removeDisallowedBlock <kit> <block>` | Remove disallowed block. |
| `/kit addExplosionBlacklist <kit> <block>` | Add explosion-protected block. |
| `/kit removeExplosionBlacklist <kit> <block>` | Remove explosion-protected block. |
| `/kit addDropWhitelist <kit> <block>` | Add block drop whitelist entry. |
| `/kit removeDropWhitelist <kit> <block>` | Remove block drop whitelist entry. |

## Staff Layout Cleanup

Bolt also exposes staff commands for custom kit layout cleanup:

| Command | Permission | Description |
| :--- | :--- | :--- |
| `/bolt deleteEveryoneKitLayout <kit>` | `bolt.admin.kitlayouts` | Deletes every player's custom layouts for the kit. |
| `/bolt deletePlayerKitLayout <player> [kit]` | `bolt.admin.kitlayouts` | Deletes one player's custom layouts, optionally only for one kit. |

## Tips

- Use `resetArenaEachRound` for scored build modes where dropped items or blocks should not carry into the next round.
- Use standalone arenas for build, BedFight, BlockFight, WallRush, Fireball, TNT, and Spleef-style kits.
- For TNTSumo, configure the kit blocks to use clay/terracotta instead of wool.
- Use `unrankedQueueEnabled` and `duelEnabled` to hide kits from specific flows without fully disabling the kit.
- Use `bolt.profile.arena` for paid or staff access to selected-arena duels/queues.
