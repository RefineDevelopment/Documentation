Bolt is Refine Development's practice core for competitive Minecraft PvP servers. It provides ranked and unranked queues, duels, parties, tournaments, events, bots, cosmetics, match history, leaderboards, divisions, kit editing, arena management, and a public developer API.

## What Bolt Includes

- **Solo, Team, FFA, Party, and Bot matches** for common practice-server workflows.
- **Ranked and Unranked queues** with ELO, divisions, ping checks, and configurable matchmaking rules.
- **Direct duels and party duels** with optional selected arena support.
- **Arena and schematic management** with standalone arenas, duplicate arenas, paste resets, and kit whitelists.
- **Modern kit rules** for BedFight, BlockFight, WallRush, Bridges, BattleRush, Fireball Fight, Pearl Fight, Spleef, Crystal PvP, TNTSumo, Boxing, Combo, OITQ, and more.
- **Tournaments and events** with cooldowns, host permissions, game rules, and automated match flow.
- **Parties** with FFA, split, party-vs-party duels, public parties, party announcements, and party settings.
- **Bots** for 1.8 practice with configurable presets, UHC healing behavior, speed behavior, knockback profiles, and kit-specific options.
- **Cosmetics and progression** including coins, experience, levels, daily rewards, kill effects, kill messages, trails, stats, and leaderboards.
- **BoltAPI** for developers who want to integrate with profiles, arenas, queues, duels, matches, parties, tournaments, kits, stats, leaderboards, and spectators.

## Requirements

| Dependency | Required | Notes |
| :--- | :---: | :--- |
| Retention | Yes | Bolt is loaded through Retention. |
| MongoDB | Yes | Stores profiles, statistics, match history, kits, and persistent data. |
| FastAsyncWorldEdit | Yes | Required by Bolt for arena schematics and paste resets. Use our FAWE-Legacy fork below. |
| ProtocolLib | Conditional | Required when `FORCE_ENTITY_HIDER` is enabled. |
| PlaceholderAPI | Optional | Enables PlaceholderAPI parsing in supported Bolt messages and menus. |
| Citizens | Optional | Required for NPC/bot-related setups that depend on Citizens. |
| Vault | Optional | Used only when your setup integrates Vault-supported economy or permissions. |

Use the Refine FAWE-Legacy build for Carbon/legacy environments:

[Download Refine FAWE-Legacy](http://github.com/refinedevelopment/fastAsyncWorldEdit-Legacy/releases/latest)

## Installation

<Steps>

1. Install Retention.
2. Install MongoDB or prepare an external MongoDB connection.
3. Install FastAsyncWorldEdit. We recommend the Refine FAWE-Legacy release linked above.
4. Place the Bolt jar in your server's plugins folder.
5. Start the server once to generate configuration files.
6. Configure `database.yml` with your MongoDB connection.
7. Configure lobby spawn, arenas, kits, queues, scoreboards, messages, and optional integrations.
8. Restart the server after major configuration or dependency changes.

</Steps>

## First Setup Checklist

<Steps>

1. Set the lobby spawn with `/bolt setspawn`.
2. Create or import arenas with `/arena create <name> <standard/standalone>`.
3. Save arena bounds, spawn points, special locations, and schematics.
4. Create kits with `/kit create <name>`.
5. Configure kit rules, inventories, queue support, duel support, and arena whitelist.
6. Enable ranked/unranked queues for the kits you want players to use.
7. Test `/duel`, `/queue join`, `/randomqueue`, `/party`, `/tournament`, and spectator flows.

</Steps>

## Common Issues

**Bolt disables itself on startup**

- Make sure FastAsyncWorldEdit is installed and enabled.
- If `FORCE_ENTITY_HIDER` is enabled, make sure ProtocolLib is installed.
- Restart the server after adding missing dependencies.

**Arena resets fail or paste arenas do not update**

- Use the recommended Refine FAWE-Legacy build.
- Check that the arena has a saved schematic.
- Use `/arena saveChanges <arena>` after editing a standalone arena.
- Use `/arena saveAllChanges` after larger schematic maintenance.

**MongoDB connection fails**

- Check host, port, username, password, database name, and authentication database in `database.yml`.
- Make sure the MongoDB server accepts remote connections from your Minecraft server.
- Check firewall rules and MongoDB user permissions.

**Players cannot host or join tournaments**

- Give `bolt.tournament.host` or `bolt.tournament.start` to hosts.
- Give `bolt.tournament.join` or the kit-specific `bolt.tournament.<kit>` permission to participants.
- Check tournament cooldowns and kit availability.
