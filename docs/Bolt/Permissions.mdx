A practical permission reference for Bolt. The list below is based on the permission checks registered or used by the current Bolt codebase.

## How To Set Permissions

LuckPerms examples:

```bash
/lp group admin permission set bolt.admin.reload true
/lp group builder permission set bolt.arena.setup true
/lp group vip permission set bolt.profile.fly true
/lp group vip permission set bolt.tournament.host true
/lp group default permission set bolt.tournament.join true
```

PermissionsEx examples:

```bash
/pex group admin add bolt.admin.reload
/pex group builder add bolt.arena.setup
/pex group vip add bolt.profile.fly
```

## Recommended Groups

| Group | Recommended permissions |
| :--- | :--- |
| Default Players | No required permission for basic duels, queues, parties, stats, cosmetics menus, and match history. Add `bolt.tournament.join` if public tournaments should be joinable. |
| VIP / Donors | `bolt.profile.fly`, `bolt.profile.ranked`, `bolt.profile.ping`, `bolt.profile.arena`, `bolt.party.limit`, `bolt.party.public`, `bolt.party.announce`, cosmetic permissions. |
| Moderators | `bolt.profile.silent`, `bolt.profile.hidebypass`, `bolt.queue.admin`, `bolt.admin.forfeit`, `bolt.event.cooldown`, `bolt.tournament.cooldown`. |
| Builders | `bolt.profile.edit`, `bolt.arena.setup`, optional `bolt.arena.admin`. |
| Admins | `bolt.admin.*` style permission from your permission plugin if supported, plus exact Bolt permissions listed below. |

Bolt registers many exact permissions. If your permission plugin supports wildcards, you may use grouped wildcards such as `bolt.admin.*`, but the safest setup is to grant the exact nodes you need.

## Tournament Permissions

| Permission | Allows |
| :--- | :--- |
| `bolt.tournament.admin` | Use admin tournament commands, force start, force end, stop, and console host. |
| `bolt.tournament.host` | Host tournaments. This also bypasses kit-specific host checks. |
| `bolt.tournament.start` | Alternative host/start permission used by the host menu and command checks. |
| `bolt.tournament.join` | Join tournaments without needing a kit-specific tournament permission. |
| `bolt.tournament.cooldown` | Reset tournament cooldowns. |
| `bolt.tournament.<kit>` | Host or join tournaments for a specific kit, such as `bolt.tournament.nodebuff`. |

Examples:

```bash
/lp group vip permission set bolt.tournament.host true
/lp group default permission set bolt.tournament.join true
/lp group uhc permission set bolt.tournament.builduhc true
```
