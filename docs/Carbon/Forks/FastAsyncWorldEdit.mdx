# FAWE Legacy

Carbon and Bolt legacy setups should use Refine Development's own FAWE-Legacy fork. This build is maintained for legacy practice-server environments where the standard FAWE release may not behave correctly on newer Java versions.

## Requirements

:::important
Use the Refine FAWE-Legacy release for Carbon/Bolt legacy setups. Install the latest build from the official Refine release page instead of older bundled jars or third-party FAWE builds.
:::

## Notes

- Restart your server after replacing FAWE.
- Do not mix random FAWE builds with Carbon/Bolt unless you have tested arena paste/reset behavior.
- If arena schematics fail to save or paste, update to the latest Refine FAWE-Legacy release first.
