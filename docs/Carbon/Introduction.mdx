## Core Features

Experience a server built for modern performance standards.

| Area | What Carbon does |
| :--- | :--- |
| **High performance** | Low-CPU tickloops and fully parallelized entity tracking for maximum TPS stability. |
| **Advanced combat** | Custom knockback profiles and hit-detection optimizations. |
| **Async everything** | Asynchronous lighting (Starlight), chunk loading, and networking for zero lag spikes. |
| **Modern developer API** | Backported Paper APIs and a rich event system for building plugins on 1.8.8. |

:::tip Why Carbon?
Carbon has rewritten core subsystems to ensure that your server remains fluid and stable even under heavy player loads, confirming consistent 20 TPS in tests with over 700+ players.
:::

## Detailed Capabilities

- **Low-CPU Tickloop & API Backports**: Modern low-CPU tickloop plus key Paper APIs—raytracing, pathfinding, richer events, and crit tracking.
- **Mouse Desync Fix**: Queues yaw/pitch-sensitive interactions to the client tick for frame-perfect accuracy.
- **Reworked Network Stack**: Slashes heavy packet writes and reduces unnecessary Netty wakeup calls.
- **Memory Leak Fixes**: Extensive fixes for safer world unloading and accurate projectile owner tracking.
