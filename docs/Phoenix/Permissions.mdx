# Permissions

Every permission Phoenix registers, grouped by the feature it belongs to. Addon
permissions are listed further down.

For how permissions attach to ranks, see
[Features/Ranks/Permissions](/Phoenix/Features/Ranks#permissions).

:::info Rank column
**Rank** is the lowest rank that holds the node in the shipped `ranks-preset.json`.
Higher ranks inherit it. A network with its own rank ladder can place these
wherever it likes &mdash; the column is a starting point, not a rule.
:::

:::note Nodes built at runtime
Five families take a suffix that only exists once your network is configured:
`core.disguise.<rank>`, `core.punish.<ladder>`, `core.grant.<rank>`,
`core.join.<server>` and `core.tags.<tag>`. The preset grants the `*` form; narrow
it per node once the names settle.
:::
