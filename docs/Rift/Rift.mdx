# Rift

Rift is the FFA and RTP PvP platform for Paper servers. It provides FFA arenas, wilderness RTP worlds, ranked RTP duels, a kit editor and kit room, cosmetics, leaderboards, scoreboards, a coin economy, and TPA.

## At a glance

| | |
| --- | --- |
| Server | Paper `1.21.11+` |
| Java | 21 |
| Loader | Retention |
| Modes | FFA arenas, World RTP, RTP duel queue |
| Storage | MySQL, MariaDB, or MongoDB |
| FFA dependency | WorldEdit or FastAsyncWorldEdit for clean schematics and recovery |
| Optional plugins | Vault, PlaceholderAPI, FancyHolograms, FancyNpcs, Oraxen, ItemsAdder, Nexo, Prism |
| API | `RiftAPI` Bukkit service |
